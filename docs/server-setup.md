# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины

- Операционная система: Ubuntu Server 24.04.5 LTS
- Оперативная память: 2048 МБ
- Процессоры: 2 ядра
- Диск: 25 ГБ, динамический

## 2. Сетевые интерфейсы

- Адаптер 1: NAT, адрес гостевой системы `10.0.2.15`; используется для исходящего доступа в Интернет.
- Адаптер 2: Host-only, адрес `192.168.56.102`; используется для доступа с хостовой Windows-системы.

## 3. Правило проброса портов

- Протокол: TCP
- Адрес и порт хоста: `127.0.0.1:2222`
- Адрес гостя: не задан
- Порт гостя: `2222`

## 4. Учётные записи

- `student`: локальная учётная запись, входит в группу `sudo`, вход по паролю.
- `devops`: входит в группу `sudo`, SSH-вход по ключу Ed25519.

## 5. Служба SSH

- Порт: `2222/tcp`
- Файл дополнительных настроек: `/etc/ssh/sshd_config.d/99-hardening.conf`
- `PermitRootLogin no`
- `PasswordAuthentication no`
- `PubkeyAuthentication yes`
- `PermitEmptyPasswords no`
- `MaxAuthTries 3`
- `LoginGraceTime 30`
- `AllowUsers devops`
- `X11Forwarding no`
- `ClientAliveInterval 300`
- `ClientAliveCountMax 2`

## 6. Правила межсетевого экрана

- UFW активен.
- Политика входящих соединений: `deny`.
- Политика исходящих соединений: `allow`.
- Разрешён TCP-порт `2222` с ограничением частоты подключений (`limit`).
- Разрешены TCP-порты `80` и `443`.

## 7. Снимки состояния

- `01-clean-install`: после установки Ubuntu Server.
- `02-keys-configured`: создан пользователь `devops`, настроен вход по SSH-ключу.
- `03-ssh-hardened`: усилена конфигурация SSH, настроены правила UFW.
